✨ 核心功能

复刻 AI HOT 模式，针对金融场景增强

📰

时间线 Feed

按日期+时间倒序展示，每日头条精选 Top 2，卡片含信源、热度、标签、推荐理由。

🔥

热度评分

0-100 分量化关注度，综合信源权重×数量×时效性×事件类型加权计算。

🏷️

标签自动分类

关键词词边界匹配，6 大维度：公司、币种、事件、主题、情绪、类型。

📡

多信源聚合

Jaccard 相似度去重，同一事件多信源报道自动合并，信源数和热度动态更新。

💡

推荐理由引擎

按事件类型自动生成编辑点评（财报、产品发布、监管、ETF、巨鲸异动等模板）。

🐋

巨鲸链上监控

支持 Whale Alert API，实时展示大额转账、交易所转入转出信号。

💰

价格看板

CoinGecko API 实时拉取 BTC/ETH/BNB/SOL/XRP 价格和 24h 涨跌。

📊

信源健康监控

追踪每个信源的抓取延迟、成功率、错误信息，/admin 页面可视化展示。

📱

移动端优化

响应式布局，卡片紧凑、价格看板横向滚动、侧边栏适配。

🚀 快速开始

本地运行或部署到 Vercel

# 克隆仓库 git clone https://github.com/boboza-art/finpuls.git cd finpulse # 安装依赖 pnpm install # 初始化种子数据 pnpm seed # 抓取 RSS 新闻（首次） pnpm fetch # 开发模式 pnpm dev # 生产构建 pnpm build && pnpm start

Deploy to Vercel

🔌 API 接口

RESTful API，支持二次开发

# 获取资讯列表 GET /api/items?tag=NVIDIA&limit=50 # 获取资讯详情 GET /api/items/{id} # 获取实时价格 GET /api/prices # 获取信源健康状态 GET /api/health # 图片代理 GET /api/img-proxy?url=...
